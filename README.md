# HiFi-Music-Ingest 无损音乐检索与自动入库

面向本地无损曲库的「搜索 → 选源 → 下载 → 自动入库」小工具。本地 Python 服务 + 浏览器界面，只监听 `127.0.0.1`，不对外网开放。

## 功能

- **单曲检索**：输入「歌手 - 歌名」，聚合 musicdl 多源（网易云、QQ音乐、酷狗、酷我、咪咕、千千）候选
- **人工选源**：展示来源、格式、大小、码率、质量分，由用户点选确认（半自动，避免误下）
- **自动下载入库**：按「歌手/专辑/歌手 - 歌名.flac|wav」写入曲库，自动写标签、嵌封面、补元数据
- **批量模式**：上传 txt/csv（每行「歌手 - 歌名」）批量入队，单条失败不阻塞整体
- **去重与日志**：入库前检测同名同歌手文件，全过程记录成功/失败/重复/跳过

## 目录结构

```
<曲库根目录>/
├── 一键启动.bat          # 安装依赖并启动服务
├── 需求规格说明文档.md    # 需求规格
├── _tool/
│   ├── server.py         # Flask 入口，监听 127.0.0.1:8756
│   ├── verify.py         # 全库校验
│   ├── requirements.txt
│   ├── app/              # 检索、下载队列、入库、标签、元数据
│   └── web/              # 前端页面（HTML/CSS/JS）
└── <歌手>/<专辑>/<文件>   # 曲库本体（不纳入版本控制）
```

## 快速开始（Windows）

1. 安装 Python 3.10，并确保 `python` 在 PATH 中。
2. 将本仓库内容放到你的无损曲库根目录下（即 `_tool` 与歌手目录同级）。
3. 双击 `一键启动.bat`：自动从清华镜像安装依赖，随后打开 `http://127.0.0.1:8756`。
4. 也可手动执行：

```bat
python -m pip install -r _tool\requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
python _tool\server.py
```

曲库根目录由 `_tool/app/config.py` 中的 `LIBRARY_ROOT` 决定（默认取 `_tool` 的上一级目录）。

## 说明

- 仅支持 FLAC / WAV 等无损格式，加密格式（`.mflac` / `.ncm` / `.mgg` 等）一律拒绝
- 检索超时、解析并发窗口、下载并发等参数见 `_tool/app/config.py`
- 运行产物（下载临时文件、缓存、队列、入库日志）写入 `<曲库根目录>/_work/`
